# 미국 급등주·매매일지 (us-surge)

미국 주식의 거래정지(halt) 종목과 +20% 급등주를 달력에서 날짜별로 보고, 분봉 차트(정지 구간 표시)·정지 이유·위험 요소·다음 날 결과를 정리하는 휴대폰용 웹앱.

자료: 나스닥 거래정지 목록(Nasdaq Trader RSS), Yahoo 시세(일봉·분봉), 나스닥 종목표(오늘 급등주), Polygon(지난 날짜 급등주, 선택), Claude + 웹 검색(이유 분석·질문).
환경변수(Vercel): `ANTHROPIC_API_KEY`(필수), `POLYGON_API_KEY`(선택).

## 📒 매매일지 (미국 주식, 달러 기준)
- 탭: 달력(날짜별 실현 손익) · 보유(지금 가격·손절/목표·관심 종목) · 통계(전략·마음별) · 복기(주간, 카톡 복사)
- 매도 손익은 평균 단가 방식. 수수료 % 자동, 환율은 Yahoo(KRW=X) 자동 또는 직접 입력, 매매마다 그때 환율 저장
- 종목 화면에서 매수·매도 기록, 차트에 ▲ 내 매수 ▼ 내 매도 표시, 💬 질문에 내 일지를 함께 보냄
- 기록은 휴대폰(localStorage)에만 저장, 일지 ⚙에서 백업 저장·불러오기
